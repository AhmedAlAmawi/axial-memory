Axial Memory

Find every Grasshopper file on your computer.

It searches the whole computer, reads inside each definition without opening Rhino, and shows which ones belong to the palm research, with the reason for each. It only reads: nothing is changed, moved or uploaded.

Download for Mac macOS 10.15 or newer · Apple silicon and Intel Download for Windows Windows 10 or 11

Installing on a Mac

  1. Open the downloaded file and drag Axial Memory into Applications.
  2. Double-click it in Applications. The Mac says it can't check the app: click Done.
  3. Open System Settings → Privacy & Security, scroll to "Axial Memory" was blocked, click Open Anyway, then Open Anyway again and enter your password.
  4. While it searches, click Allow when the Mac asks about folders.

Only the first time. Updates install themselves from inside the app.

Installing on Windows

  1. Open the downloaded file.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway.
  3. Follow the installer. No administrator password is needed.

Only the first time. Updates install themselves from inside the app.

Two laptops

Install it on both and search each. On one, open Laptops and click Save this laptop's scan; send that file to yourself; on the other, click Add the other laptop's scan. Everything then shows together, with copies found on both.
