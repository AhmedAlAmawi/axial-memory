# Installing on Windows

1. Download **Axial-Memory-Windows-setup.exe** from
   https://github.com/AhmedAlAmawi/axial-memory/releases/latest/download/Axial-Memory-Windows-setup.exe
2. Open it. Windows may show *"Windows protected your PC"*: click **More info**,
   then **Run anyway**.
3. Follow the installer (no administrator password needed). Axial Memory opens
   at the end and is in the Start menu afterwards.

You only do this once; updates install themselves from inside the app.

If the browser warns about the download, choose **Keep**. If antivirus software
quarantines it, allow it: the app only reads files and never changes them.
